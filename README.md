# ASCII Koi Pond

A living koi pond drawn entirely with text characters. Named koi swim, turn, flick their fins and tails, and come to eat when you feed them. Feed the pond enough and a baby koi hatches and slowly grows up. A big ASCII clock and today's date sit under the water, with bobbing lily pads, lotus flowers, bubbles and rain. The pond follows the real time of day, with warm sunsets and fireflies at night.

## Controls

| Action | What it does |
| --- | --- |
| Click / tap | Splash: ripples spread and nearby koi dart away (click a lily pad to make it bob) |
| Click / tap a koi | Say hi and see its name |
| Hover a koi | See its name |
| Double-click a koi | Rename it |
| Right-click / hold | Drop food: koi swim over and eat it |
| `1` `2` `3` | Change the water (teal, ink, paper) |
| `5` | Start / stop the rain |
| `C` | Show / hide the clock and date |
| `M` | Sound on / off |
| `S` or ⚙ | Settings |
| `Space` | Pause |

## Settings

Number of koi, koi size, water colour, time of day (auto / day / sunset / night), 12- or 24-hour clock, seconds, rain, sound and volume, always-show names, and a list of your koi to rename. Your settings and koi are remembered in your browser.

## Sound

All sounds are generated in the browser (no audio files): soft water, plips when you feed, splashes, bubble pops, rain and a little chime when a baby hatches. Sound starts off; press `M` to turn it on.

## Run it

Open `index.html` in any browser. No install or build step: it's one self-contained file.
