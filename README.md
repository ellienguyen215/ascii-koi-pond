# ASCII Koi Pond

A living koi pond drawn entirely with text characters. Koi swim, turn, flick their fins and tails, and come to eat when you feed them.

## Controls

| Action | What it does |
| --- | --- |
| Click / tap | Splash — ripples spread and nearby koi dart away |
| Right-click / hold | Drop food — koi swim over and eat it |
| `1` `2` `3` | Change the water (teal, ink, paper) |
| `Space` | Pause |

## Run it

Open `index.html` in any browser. No install or build step — it's one self-contained file.

To host it for free, turn on **GitHub Pages** for this repo (Settings → Pages → Deploy from branch → `main` / root). It will be live at `https://<your-username>.github.io/ascii-koi-pond/`.
