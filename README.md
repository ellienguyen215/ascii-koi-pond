# ASCII Koi Pond

A living koi pond drawn entirely with text characters. Koi swim, turn, flick their fins and tails, and come to eat when you feed them. A big ASCII clock and today's date sit under the water, with bobbing lily pads, lotus flowers, bubbles and rain.

## Controls

| Action | What it does |
| --- | --- |
| Click / tap | Splash — ripples spread and nearby koi dart away (click a lily pad to make it bob) |
| Right-click / hold | Drop food — koi swim over and eat it |
| `1` `2` `3` | Change the water (teal, ink, paper) |
| `5` | Start / stop the rain |
| `C` | Show / hide the clock and date |
| `Space` | Pause |

## Run it

Open `index.html` in any browser. No install or build step — it's one self-contained file.

To host it for free, turn on **GitHub Pages** for this repo (Settings → Pages → Deploy from branch → `main` / root). It will be live at `https://<your-username>.github.io/ascii-koi-pond/`.
